🏗️ System Overview

ภาพรวมระบบ

ระบบ Smart Parking Management System คือระบบจัดการลานจอดรถอัจฉริยะแบบครบวงจร ตั้งแต่รถเข้า-ออก การชำระเงิน ไปจนถึงการแนะนำด้วย AI

🚗
การจัดการจอดรถ
รองรับยานพาหนะ 4 ประเภท: รถยนต์, มอเตอร์ไซค์, รถยนต์ไฟฟ้า (EV) และรถบรรทุก พร้อมระบบออกตั๋วอัตโนมัติ แอนิเมชันไม้กั้น และจัดสรรช่องจอดอัจฉริยะ
💳
การชำระเงินหลากหลายช่องทาง
รองรับ 3 ช่องทางชำระเงิน: PromptPay QR Code, บัตรเครดิต/เดบิต และเงินสด พร้อมคำนวณเงินทอนอัตโนมัติ และออกใบเสร็จรับเงิน
🤖
ระบบ AI อัจฉริยะ
ผสาน AI เข้ากับทุกขั้นตอน: แนะนำช่องจอดพร้อมเหตุผล (XAI), สแกนป้ายทะเบียนอัตโนมัติ (ANPR), พยากรณ์ความหนาแน่น และ AI Copilot Chatbot
📐 Architecture

สถาปัตยกรรมระบบ

ระบบออกแบบเป็น Layered Architecture แยกส่วนชัดเจน ตามหลัก Separation of Concerns

🖥️ Presentation Layer (Frontend)
index.html + style.css + app.js — Modern SPA ด้วย Glassmorphism Design, REST Client
⬇ HTTP REST API (JSON) ⬇
🌐 Server Layer (ParkingServer.java)
Pure Java SE HttpServer — ลงทะเบียน 15 API Endpoints, Static File Server, CORS
⬇ ⬇
⚙️ Service Layer / Facade (ParkingService.java)
Business Workflow Controller: Check-in, Check-out, Payment, Time Simulation
⬇ ⬇
🤖 AI Layer (AIParkingService.java)
XAI Recommendation, ANPR, Traffic Prediction, Copilot Chat
🏛️ Domain Layer (Models, Strategies, Factories)
Vehicle, Slot, Ticket, ParkingLot, PricingStrategy, Observer
⬇ ⬇
💾 Repository Layer (In-Memory Storage)
TicketRepository + PaymentRepository — ข้อมูลเก็บใน ConcurrentHashMap

📋 รายละเอียดทีละขั้นตอน

ขั้นตอนที่ 1 — Entry Gate (จุดตรวจทางเข้า)
รถเข้าจอดและออกตั๋ว (Check-In)
ผู้ใช้ป้อนเลขทะเบียน (หรือให้ AI ANPR สแกนอัตโนมัติ) ➜ เลือกประเภทยานพาหนะ ➜ ระบบใช้ VehicleFactory สร้าง Object รถ ➜ ParkingLot (Aggregate Root) จัดสรรช่องจอดด้วย SlotAllocationStrategy ➜ สร้าง Ticket (สถานะ ACTIVE) ➜ แสดงแอนิเมชันไม้กั้นเปิด ➜ AI แนะนำช่องจอดที่ดีที่สุดพร้อมคำอธิบาย (XAI)
ขั้นตอนที่ 2 — Lot Map (แผนผังจอดรถ)
มอนิเตอร์สถานะแบบเรียลไทม์
หน้าจอแผนผัง 2D แสดงช่องจอดรถทั้ง 3 ชั้น แยกสีตามสถานะ: 🟢 ว่าง / 🔴 มีรถจอด / 🔵 EV Charging ➜ คลิกที่ช่องจอดเพื่อดูข้อมูลรถ, เวลาเข้า, กลยุทธ์ราคา และค่าบริการสะสม ➜ Observer Pattern (DisplayBoard) คอยอัปเดตจำนวนที่ว่างแบบเรียลไทม์
ขั้นตอนที่ 3 — Time Travel (เร่งเวลา)
จำลองเวลาเพื่อทดสอบ
ระบบ Clock Simulation ช่วยให้ทดสอบค่าจอดได้ทันที: ปุ่ม +15 นาที, +1 ชั่วโมง, +3 ชั่วโมง, +1 วัน ➜ ระบบคำนวณค่าจอดตาม PricingStrategy ที่สอดคล้องกับประเภทรถและระยะเวลาที่เปลี่ยนไป ➜ ทำให้ทดสอบกฎการคำนวณเงินทุกกรณีได้สะดวกรวดเร็ว
ขั้นตอนที่ 4 — Exit & Cashier (ชำระเงินและออก)
คำนวณค่าจอดและชำระเงิน
ค้นหาตั๋วด้วยเลขตั๋วหรือป้ายทะเบียน ➜ ระบบคำนวณค่าจอดผ่าน PricingStrategy (Polymorphism) ➜ เลือกช่องทางชำระเงิน (PromptPay / บัตรเครดิต / เงินสด) ➜ Payment (Abstract Class) ➜ ตั๋วเปลี่ยนสถานะเป็น PAID ➜ ออกใบเสร็จ ➜ กดออก (EXIT) ➜ ช่องจอดถูกปลดปล่อย ➜ DisplayBoard อัปเดตจำนวนที่ว่าง
ขั้นตอนที่ 5 — กรณีพิเศษ
ตั๋วหาย (Lost Ticket)
หากผู้ใช้ทำตั๋วหาย ➜ กดปุ่ม "ตั๋วหาย" ➜ ระบบคิดค่าปรับเหมาจ่าย 300 บาท ➜ ตั๋วเปลี่ยนสถานะเป็น LOST ➜ ชำระเงินและนำรถออก ➜ ระบบบันทึกประวัติไว้ครบถ้วน
🤖 Artificial Intelligence

ระบบปัญญาประดิษฐ์ (AI)

AI 5 โมดูลที่ช่วยยกระดับประสบการณ์ผู้ใช้ พร้อมอธิบายเหตุผลทุกการตัดสินใจ (Explainable AI)

🧠 Powered by AIParkingService.java — 415 Lines of AI Logic

คำอธิบายการทำงานของ AI ในระบบ

AI ทั้ง 5 โมดูลถูกออกแบบเป็น Rule-Based Expert System ที่ทำงานภายในตัว (On-Device) ไม่ต้องเชื่อมต่ออินเทอร์เน็ตหรือ Cloud API ภายนอก ทุกการตัดสินใจมี "คำอธิบาย" ประกอบตามหลัก Explainable AI (XAI) เพื่อให้ผู้ใช้เข้าใจว่า AI คิดอย่างไร

  • 1

    🎯 XAI Smart Slot Recommendation

    แนะนำช่องจอดที่ดีที่สุดด้วย Multi-Criteria Optimization Algorithm คำนวณ 4 ปัจจัย: ความเข้ากันได้ของรถกับช่องจอด, การสงวนจุดชาร์จ EV, การกระจายความหนาแน่น (Load Balancing), และระยะทางเดิน ➜ แสดง "คะแนนความเหมาะสม" และ "ปัจจัยที่ AI พิจารณา" ทุกข้อ ➜ ความเชื่อมั่น 96%

  • 2

    📷 ANPR / LPR (อ่านป้ายทะเบียนอัตโนมัติ)

    จำลองระบบ Automatic Number Plate Recognition (Computer Vision) สแกนป้ายทะเบียนจากกล้อง CCTV ➜ AI จำแนกประเภทยานพาหนะ (รถยนต์/EV/มอเตอร์ไซค์/รถบรรทุก) อัตโนมัติ ➜ ความแม่นยำ 98.4-99.9% ➜ แสดงผลตรวจจับ เช่น "2-Wheeled Chassis, Handlebars detected"

  • 3

    📊 Predictive Traffic & Dynamic Pricing

    พยากรณ์ความหนาแน่นของลานจอด 24 ชั่วโมงล่วงหน้า ➜ วิเคราะห์ช่วงเร่งด่วน (Peak Hours: 07:00-09:00, 11:00-13:00) ➜ แนะนำ Dynamic Pricing Surge Multiplier (1.0x - 1.25x) ➜ ให้คำอธิบายเหตุผลเชิงพฤติกรรมผู้ใช้บริการ

  • 4

    💼 Executive Analytics & Insights

    บทวิเคราะห์สำหรับผู้บริหาร: Efficiency Score (94.2%), ดัชนีคาร์บอนที่ประหยัดได้, อัตราหมุนเวียนเฉลี่ย (2.4 รอบ/ช่อง/วัน), รายได้คาดการณ์ ➜ วิเคราะห์แยกชั้น ➜ แนะนำ 4 ข้อเสนอ เช่น ขยายจุดชาร์จ EV, เปิดทางออก 2 ช่อง ฯลฯ

  • 5

    💬 AI Copilot Chatbot (Grounded)

    แชตบอทอัจฉริยะที่ดึงข้อมูลจากฐานข้อมูลจริง (Grounded AI) ตอบได้ 6 หมวด: SLOT_AVAILABILITY, REVENUE_FINANCE, EV_CHARGING, PRICING_STRATEGY, OOP_ARCHITECTURE, GENERAL ➜ ตอบด้วยตัวเลขและสถานะสดจริง ไม่ใช่ข้อมูลสร้างขึ้น

🔍 ทำไมต้องมี Explainable AI (XAI)?

ระบบ AI ในที่จอดรถนี้ไม่ใช่ "กล่องดำ" (Black Box) — ทุกการตัดสินใจจะมี คำอธิบายว่าทำไม AI ถึงแนะนำแบบนั้น เช่น "AI แนะนำช่อง F1-01 เพราะ (1) ตรงกับความต้องการชาร์จ EV (+35 คะแนน), (2) ชั้น 1 มีพื้นที่โล่ง (+10 คะแนน)" ➜ ช่วยให้ผู้ใช้เชื่อมั่นและเข้าใจ ➜ สอดคล้องกับหลักจริยธรรม AI สากล (Trustworthy AI)

หลักการ OOP และ Design Patterns

ระบบนี้ออกแบบตามหลัก OOP 4 เสาหลัก และประยุกต์ใช้ 4 Design Patterns

1. Abstraction (นามธรรม)
Vehicle — คลาสแม่นามธรรมสำหรับยานพาหนะ ซ่อนรายละเอียดภายในและบังคับเมธอด canParkIn(Slot), getPricingStrategy()

Payment — คลาสแม่นามธรรมสำหรับการชำระเงิน บังคับ processPayment()

PricingStrategy & SlotAllocationStrategy — อินเตอร์เฟสกำหนดสัญญาการคิดราคาและจัดสรรช่องจอด
2. Encapsulation (การห่อหุ้ม)
Slot — ปกป้อง Invariants: ห้ามรับรถใหม่เมื่อสถานะเป็น OCCUPIED, จัดการจอง/ปลดปล่อยผ่าน assignVehicle() และ release() แบบ Thread-Safe

Ticket — ควบคุม State Transition (ACTIVE → PAID → EXITED หรือ LOST) ห้ามแก้ไขค่าธรรมเนียมจากภายนอก
3. Inheritance (การสืบทอด)
Vehicle ➔ Car, Motorcycle, ElectricVehicle, Truck
➜ คลาสลูกแต่ละประเภทสืบทอดคุณสมบัติและปรับพฤติกรรมเฉพาะตน

Payment ➔ PromptPayPayment, CreditCardPayment, CashPayment
➜ แต่ละช่องทางชำระเงินมีตรรกะการประมวลผลเฉพาะของตนเอง
4. Polymorphism (พหุสัณฐาน)
Double Dispatch: slot.canFitVehicle(vehicle) ส่งต่อให้ vehicle.canParkIn(this) ➜ รถแต่ละชนิดตัดสินเองว่าจอดในช่องนี้ได้หรือไม่

Strategy Polymorphism: PricingStrategy.calculateFee() ➜ ผลลัพธ์แปรผันตามประเภทรถและระยะเวลาจริง โดยไม่ต้อง if-else

🧩 Design Patterns ที่ใช้ในระบบ

🎯 Strategy Pattern
แยกตรรกะการคิดเงินออกจากคลาสหลัก เพิ่ม/ปรับกลยุทธ์ราคาใหม่ได้โดยไม่แก้โค้ดเดิม (Open-Closed Principle)
PricingStrategy.java StandardPricingStrategy.java EVPricingStrategy.java MotorcyclePricingStrategy.java TruckPricingStrategy.java
👁️ Observer Pattern
ParkingLot เป็น Subject ส่งการแจ้งเตือนเมื่อรถเข้า-ออก ➜ DisplayBoard (Observer) อัปเดตจำนวนที่ว่างแบบเรียลไทม์
ParkingLotObserver.java DisplayBoard.java ParkingLot.java
🏭 Factory Pattern
ใช้ Factory สร้าง Object รถและช่องจอดตามประเภท แยกตรรกะการสร้างออกจากการใช้งาน
VehicleFactory.java SlotFactory.java
🎭 Facade / Aggregate Root
ParkingLot เป็น Aggregate Root ควบคุม Floor & Slot, ParkingService เป็น Facade เชื่อมทุก Domain
ParkingLot.java ParkingService.java
🔌 REST API

API Endpoints

RESTful API ทั้ง 15 เส้นทาง ให้บริการผ่าน Pure Java SE HttpServer บนพอร์ต 8080

Method Endpoint คำอธิบาย หมวด
GET /api/status ข้อมูลสถานะภาพรวมของลานจอดรถ (จำนวนว่าง/จอดอยู่) Core
GET /api/lot ข้อมูลผังลานจอดรถ แยกชั้น แยกช่อง พร้อมสถานะ Core
POST /api/park นำรถเข้าจอด (Check-in) ส่ง vehicleType, licensePlate Core
POST /api/calculate-fee คำนวณค่าบริการจอดรถ (ก่อนชำระจริง) Core
POST /api/pay ชำระเงินค่าบริการจอดรถ (PromptPay/Credit/Cash) Payment
POST /api/exit นำรถออก (Check-out) ปลดปล่อยช่องจอด Core
POST /api/lost-ticket แจ้งตั๋วหาย — คิดค่าปรับ 300 บาท Core
POST /api/time-travel จำลองเลื่อนเวลา (+15m, +1h, +3h, +1d, reset) Simulation
GET /api/tickets รายการตั๋วทั้งหมดในระบบ History
GET /api/payments รายการประวัติการชำระเงินทั้งหมด History
POST /api/ai/recommend AI แนะนำช่องจอดที่ดีที่สุดพร้อมคำอธิบาย (XAI) 🤖 AI
POST /api/ai/anpr สแกนป้ายทะเบียนและจำแนกประเภทรถ (ANPR) 🤖 AI
GET /api/ai/predict พยากรณ์ความหนาแน่น + Dynamic Pricing Advisory 🤖 AI
GET /api/ai/insights บทวิเคราะห์สำหรับผู้บริหาร (Executive Analytics) 🤖 AI
POST /api/ai/chat AI Copilot แชตบอทอัจฉริยะ (Grounded AI) 🤖 AI

📝 Summary

สรุปการทำงานของระบบ

🏆 Smart Parking Management System — สรุปภาพรวม

ชื่อระบบ: Smart Parking Management System (OOP-Driven Full Stack Web Application)

วัตถุประสงค์: ระบบบริหารจัดการลานจอดรถอัจฉริยะ ครอบคลุมตั้งแต่ทางเข้า (Entry Gate), ระบบจัดสรรช่องจอด (Slot Allocation), การชำระเงินหลายช่องทาง (Multi-Channel Payment), ไปจนถึงระบบ AI แนะนำและพยากรณ์

🏗️ สถาปัตยกรรม: Layered Architecture 6 ชั้น (Frontend → Server → Service → AI → Domain → Repository)

🏛️ หลักการ OOP: Abstraction, Encapsulation, Inheritance, Polymorphism

🧩 Design Patterns: Strategy, Observer, Factory, Facade / Aggregate Root

🤖 AI Features: XAI Slot Recommendation, ANPR, Traffic Prediction, Executive Insights, Copilot Chatbot

📱 อุปกรณ์ที่ทำงานร่วมกัน: กล้อง CCTV (ANPR), ไม้กั้นอัตโนมัติ, ป้ายไฟ LED, แท่นชาร์จ EV, เครื่องพิมพ์ตั๋ว, เครื่องรับชำระเงิน, เซ็นเซอร์ IoT, เซิร์ฟเวอร์ควบคุมกลาง

💰 การชำระเงิน: PromptPay QR Code, บัตรเครดิต/เดบิต, เงินสด (คำนวณเงินทอนอัตโนมัติ)

🚗 ยานพาหนะ: รถยนต์ (Standard/Compact), มอเตอร์ไซค์, รถยนต์ไฟฟ้า (EV), รถบรรทุก (Truck)

⚡ เทคโนโลยี: Pure Java SE 26 + HTML5/CSS3/JavaScript — ไม่ใช้ Framework ภายนอก

🔌 API: 15 REST API Endpoints (10 Core + 5 AI)

🧪 Testing: Automated Unit Tests ผ่าน ParkingSystemTest.java

📦 Deployment: 1-Click ผ่าน run.bat → Compile + Test + Start Server + Open Browser
