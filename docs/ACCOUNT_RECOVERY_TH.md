# บัญชีและการกู้รหัสผ่าน

## เปลี่ยนรหัสเมื่อยังเข้าได้

กด **เปลี่ยนรหัสผ่าน** ที่แถบบน กรอกรหัสเดิมและรหัสใหม่ 12–128 ตัวอักษร
หลังบันทึกต้องเข้าสู่ระบบใหม่ทุกเครื่อง รหัสผ่านไม่ถูกบันทึกใน Audit Log
หน้า **ผู้ใช้ / บริษัท** ให้เจ้าของปิด/เปิดบัญชีทีมงานหรือยกเลิก Session ได้
เจ้าของบริษัทจัดการได้เฉพาะ admin/staff ของตนเอง ไม่สามารถปิดตนเองหรือ superadmin

## ลืมรหัส superadmin บน EC2

ใช้หลัง deploy เวอร์ชันที่มี `platform.AdminRecovery` แล้ว และต้องไม่มี deploy อีกงานกำลังรัน
ขั้นตอนนี้หยุดแอปชั่วคราว สำรอง PostgreSQL และเริ่มแอปกลับแม้ยกเลิกการกรอก
รองรับ Compose เครื่องเดียวตาม `compose.aws.yml`; หากมีหลาย app ต้องหยุดทุก instance ก่อน

ใน EC2 Instance Connect:

```bash
cd /opt/parking-platform
bash scripts/recover-admin.sh
```

พิมพ์ `RESET superadmin` เมื่อถาม จากนั้นกรอกรหัสใหม่สองครั้ง (หน้าจอไม่แสดงรหัส)
ข้อมูลบริษัท ลาน ตั๋ว สมาชิกและประวัติยังอยู่เดิม ไม่ต้อง DELETE หรือ reset volume
หาก backup ล้มเหลว สคริปต์หยุดก่อนแก้บัญชี หากไม่มี superadmin สคริปต์ไม่สร้างสิทธิ์ใหม่เอง

Secret `PLATFORM_ADMIN_PASSWORD` ใช้เฉพาะฐานข้อมูลใหม่ การแก้ Secret ไม่รีเซ็ตรหัสเดิม
อย่าใส่รหัสในคำสั่ง shell, URL, Issue หรือแชต ให้เก็บรหัสใหม่ใน password manager
การเปิดบัญชีที่ถูกปิดไม่ทำให้ Session เก่ากลับมาใช้ได้

## ขอบเขต

ยังไม่มีการส่งลิงก์รีเซ็ตทางอีเมลหรือ MFA การกู้ผ่าน console ต้องเป็นผู้ดูแล EC2 ที่ได้รับสิทธิ์
Backup อยู่ใน `backups/` สิทธิ์เฉพาะผู้รัน มีชื่อแยกแต่ละครั้งและลบสำเนาเก่ากว่า 7 วัน
ควรทดสอบ restore ในฐานข้อมูลแยกและจัดเก็บสำเนานอก EC2 ก่อนรับข้อมูลลูกค้าจริง
