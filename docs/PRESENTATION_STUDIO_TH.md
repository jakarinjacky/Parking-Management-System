# GreenPark Presentation Studio

โหมดสาธิตบน Java API และฐานข้อมูลเดียวกับแพลตฟอร์ม ใช้ข้อมูลสมมุติในลานเฉพาะ ไม่ต้องเปิด PLATFORM_DEMO หรือเผยแพร่รหัสบัญชีเริ่มต้น

## เริ่มพรีเซนต์
1. Deploy main ผ่าน workflow Deploy Platform to AWS EC2
2. เข้าบัญชีเจ้าของลูกค้า ถ้าเป็นเจ้าของแพลตฟอร์มให้เลือกบริษัทลูกค้าก่อน
3. หน้า dashboard.html กด เปิดลานพรีเซนต์ หรือหน้า platform.html > ลานจอดทั้งหมด > ลานพรีเซนต์
4. ระบบสร้างลานสองชั้น มีถนน ทางเข้าออก ช่องรถยนต์ EV มอเตอร์ไซค์ รถบรรทุก VIP และผู้พิการ พร้อมประวัติสมมุติ 3 เดือน กดซ้ำจะเปิดลานเดิม

## ลำดับสาธิต 5 นาที
- รับรถเข้า: เลือกประเภทรถ กดสแกนจำลอง ระบบสุ่มทะเบียนและแนะนำช่องที่เหมาะสม จากนั้นออกบัตร
- เร่งเวลา: +15 นาที / +1 ชั่วโมง / +3 ชั่วโมง / +1 วัน
- รถออก: ค้นหาทะเบียน ตรวจค่าจอด เลือกวิธีชำระ กดจำลองรับชำระสำเร็จ แล้วกดนำรถออก
- ประวัติ: ดูรายการและส่งออก Excel
- สมาชิกและการจอง: เพิ่มสมาชิกและจองช่องล่วงหน้าจากเมนูแยก
- ออกแบบ: เปิดแพลตฟอร์ม ปรับผัง บันทึกแบบร่าง ตรวจผังและเผยแพร่ ผังใหม่ใช้ร่วมกับ Dashboard
- OOP: อธิบาย ParkingLayout, PlatformService, PricingPolicy, PlatformStore และเส้นทางทำงานในแท็บ OOP
- บัญชีย่อย: เจ้าของสร้างพนักงานและมอบหมายลานพรีเซนต์ให้ เพื่อสาธิตการจำกัดสิทธิ์

## เริ่มรอบใหม่
ปุ่ม เริ่มสาธิตใหม่ ลบรายการทดลองเฉพาะลานที่ระบบสร้างเป็นลานพรีเซนต์ คืนผังเริ่มต้น สมาชิก ประวัติ และเวลา ต้องยืนยันก่อนทำ ไม่แก้ลานอื่น

กล้อง ANPR ไม้กั้น การชำระเงิน และคำตอบผู้ช่วยเป็นการจำลอง/กฎที่กำหนดไว้ ไม่มีการวิเคราะห์ภาพจากกล้องหรือเรียกเก็บเงินจริง รายการชำระลานตัวอย่างระบุ SIMULATED_ เสมอ บัญชีและข้อมูลยังตรวจสิทธิ์บนเซิร์ฟเวอร์

หน้าล็อกอินใช้ CSS 3D ไม่ต้องโหลดโมเดลภายนอก และหยุดการเคลื่อนไหวเมื่ออุปกรณ์เลือก Reduce motion
